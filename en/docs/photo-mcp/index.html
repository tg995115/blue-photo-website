Blue Photo connector guide

Browse the Suwon Samsung Bluewings photo archive by player, match or competition. Connect a Blue Photo account to search published photos, open watermarked previews and manage your favorites.

Connect an account

Use Streamable HTTP at https://bluewings.photo/mcp. Discover the authorization server through the resource metadata. Registered clients use authorization code with PKCE S256. Include the MCP endpoint as the resource and use your registered redirect URI. The user signs in on Blue Photo and approves the requested scopes.

photos.read allows public browsing and usage checks. Also request photos.favorite to read or update the connected account’s favorites. An insufficient-scope challenge requires fresh consent. Refresh tokens preserve the granted scopes.

Tools

search_collections
Read collection cards by kind, with optional query and page. Use PLAYER to find a player, then keep the returned collection ID when narrowing results. Use FAVORITES for the linked account’s favorites card.
search_photos
Search globally or within a collection using its ID, query and page. For favorites, use collectionId favorites without a query. Use the returned nextPage with the same filters to continue. Each successful call consumes one view.
get_photo
Open one published photo using its exact photoId. Each successful call consumes one view. Preview availability is checked when the image is requested.
get_usage
Call with an empty object to read used, limit and resetsAt. This does not consume a view.
set_photo_favorite
Set photoId and the desired boolean isFavorited only after the user selects a heart or explicitly requests the change. The tool returns the resulting favorite state. Repeating the same write is idempotent and does not consume a view.

Daily allowance

Standard accounts share ten photo views per day across connections, resetting at midnight in Korea. Collection searches and preview image requests do not use this allowance. At the limit the connector returns usage and the app download link. Read get_usage for the connected account’s actual allowance.
